# RoadTraining App

Aplicación personal para el seguimiento de rutinas de entrenamiento funcional.

## Cómo ejecutar

Simplemente abre el archivo `index.html` en tu navegador web.

Si tienes problemas cargando las imágenes o los scripts, puedes iniciar un servidor local rápido con Python:

```bash
python -m http.server
```

Luego abre tu navegador en `http://localhost:8000`.

## Tecnologías utilizadas
- HTML/CSS (Tailwind CSS vía CDN)
- React.js (vía CDN)
- Babel (para compilar JSX en el navegador)
